# Computer Programming

## Unit 2: Classes and Objects

In this unit, you will learn how Java uses **classes and objects** to create your own custom data types.

* Understand what a **class** is and how it groups related data together.
* Create custom data types using **instance variables** and **constructors**.
* Create objects using `new` and pass **arguments** to constructors.
* Understand the difference between a **class** and an **object**.
* Use **constructor parameters** and arithmetic expressions when creating objects.
* Use `private`, `public`, and `this` to control access to data and practice **information hiding**.
* Understand how variables and objects are stored in **memory**, including the stack, heap, primitive values, and references.
* Understand **variable scope** and how it affects where variables can be used.
* Recognize common exceptions related to objects, including `NullPointerException`.

This unit comes with a library of classes. Their documentation can be found [here](./SimpleClassLibDocs.md)
